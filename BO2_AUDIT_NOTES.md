# Black Ops II beginner-depth audit

This audit treats a first-time player as the target reader.

## Rules enforced

- Every main-quest step includes an exact location and a complete action description.
- Required preparation is separated from optional side Easter eggs.
- Buildables list each part's spawn pool instead of saying only to find the parts.
- Images and diagrams appear inside the step that uses them.
- Randomized puzzles explain how to derive the current match's solution.
- Vanilla player-count locks are stated on the map and quest.
- Community Plutonium links are displayed only for maps that need a multiplayer adaptation.
- Origins remains marked as naturally solo-capable.

## Scope

- TranZit
- Nuketown Zombies
- Die Rise
- Mob of the Dead
- Buried
- Origins

## Primary walkthrough sources

- Call of Duty Wiki / Fandom
- Call of Duty Zombies guide library
- Map-specific community references linked on each guide
